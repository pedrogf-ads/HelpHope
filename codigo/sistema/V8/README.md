## Análise

A versão V8 do HelpHope contém uma implementação de frontend e backend.

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* Node.js
* Express.js
* PostgreSQL
* JWT Authentication
* Bcrypt
* CORS
* Helmet
* Rate Limiting
* API REST

## Observação

Os arquivos-fonte do backend foram incluídos para fins de documentação, versionamento e demonstração da arquitetura do sistema.

A implantação completa da infraestrutura de produção, incluindo servidor, banco de dados e hospedagem, não faz parte do escopo desta versão acadêmica do projeto.

Dessa forma, os arquivos disponibilizados representam a estrutura desenvolvida durante a construção do sistema HelpHope.
