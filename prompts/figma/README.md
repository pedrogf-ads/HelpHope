# Prompts Figma — HelpHope

Este diretório contém os prompts utilizados durante a evolução do protótipo HelpHope no Figma.

## Organização

- `prompts_individuais/`: um arquivo para cada prompt.
- `todos-os-prompts.md`: todos os prompts reunidos em um único arquivo.
- `INDICE.md`: lista dos prompts.

## Observação

A maior parte dos prompts foi elaborada com auxílio do ChatGPT.
Algumas pequenas alterações foram realizadas manualmente durante o desenvolvimento do projeto.

Os textos foram mantidos conforme o documento original enviado.
