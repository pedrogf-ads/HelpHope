# Prompt 1 - Inicial

Crie o design de um aplicativo mobile moderno chamado HelpHope, voltado para apoio a crianças com Transtorno do Espectro Autista (TEA) e câncer, utilizado por terapeutas, familiares e doadores de uma ONG (ASIPECA).
O design deve transmitir acolhimento, esperança, confiança e profissionalismo, com foco em usabilidade e acessibilidade.
🎨 IDENTIDADE VISUAL Baseado na logo fornecida (usar como referência principal de identidade visual) Paleta de cores com foco em verde (cor principal da ONG): Verde principal: #4CAF50 Verde claro: #A5D6A7 Verde suave/pastel: #E8F5E9 Azul complementar: #64B5F6 Branco: #FFFFFF Cinza leve: #F5F5F5 Estilo: UI clean (sem poluição visual) Design moderno estilo app de saúde Cantos arredondados Sombras suaves Ícones amigáveis e acessíveis Tipografia simples (ex: Inter, Poppins ou Roboto) 🔐 TELA DE LOGIN (MULTI-ACESSO)
Criar uma tela de login intuitiva com 3 perfis de acesso bem definidos visualmente:
Tipos de usuário: 🧑‍⚕️ Terapeuta (institucional) 👨‍👩‍👧 Paciente / Família 💚 Doador Campos: Email Senha Diferenciais: Seleção de perfil com cards ou botões ilustrados Indicação visual clara do tipo de acesso Terapeutas: apenas emails institucionais (validação visual) 💚 FLUXO DO DOADOR
Após selecionar “Doador”, apresentar opções claras:
Formas de doação: 📱 Pix 💳 Cartão 📦 Doação física (medicamentos, alimentos, etc.) 📞 Botão “Entrar em contato com a ONG” Extras: Exibir campanhas em destaque Mostrar necessidades urgentes Design emocional e engajador 🏠 DASHBOARD – TERAPEUTA (VISÃO GERAL)
Após login como terapeuta:
Exibir: 📊 Indicadores principais (cards): Evolução das terapias (%) Número de pacientes ativos Status das crianças Colaboradores ativos Estoque (remédios, alimentos, materiais) 📈 Gráficos: Linha (evolução) Pizza (distribuição) Barras (atividades) Layout estilo painel administrativo moderno 📅 AGENDAMENTO (IMPORTANTE – ADICIONADO)
Criar uma aba dedicada:
Agenda semanal/mensal Marcação de consultas Visualização por paciente Status: Confirmado Pendente Cancelado 👶 ÁREA DE PACIENTES (ESTRUTURA PROFISSIONAL)
Organização correta (IMPORTANTE):
📌 Estrutura ideal: Lista de salas/grupos → Lista de pacientes → Ao clicar no paciente: Dashboard individual + Prontuário 📊 DENTRO DO PACIENTE (CENTRALIZADO)
Tudo relacionado ao paciente fica aqui (melhor prática profissional):
👤 Informações: Nome, idade Nível de TEA Tipo/estágio do câncer 📊 Dashboard do paciente: Evolução terapêutica Indicadores visuais 📋 Prontuário: Histórico médico Observações terapêuticas 💊 Medicamentos: Nome Horário Dias 🧩 Atividades: Programação terapêutica 📑 DOCUMENTOS (ORGANIZAÇÃO PROFISSIONAL)
Criar uma aba chamada:
📂 “Documentos Clínicos”
Dentro dela:
📄 Prontuários 📑 Relatórios 📝 Atestados 📃 Declarações
✔️ (Melhor prática: tudo centralizado e padronizado)
📊 RELATÓRIOS GERAIS
Tela separada com:
Dados gerais das terapias Desempenho institucional Uso de recursos Gráficos: Pizza Barra Linha 🤝 ÁREA INSTITUCIONAL (COLABORADORES)
Separar como uma aba:
Conteúdo: 💰 Doações recebidas 📦 Necessidades das famílias 📢 Campanhas ℹ️ Informações da ONG ASIPECA 👨‍👩‍👧 ÁREA PACIENTE / FAMÍLIA (SIMPLIFICADA)
Interface mais simples e acessível:
Exibir: Informações da criança Rotina diária Medicamentos Atividades
🚫 Sem acesso a:
Dados administrativos Outros pacientes 🧭 NAVEGAÇÃO
Utilizar:
Bottom navigation (mobile) Ícones claros Abas principais (terapeuta): Home Pacientes Agenda Relatórios Institucional 🎯 DIFERENCIAIS IMPORTANTES Design acessível (contraste, legibilidade) UX simples e intuitiva Feedback visual (botões, estados) Sensação de cuidado e acolhimento Organização profissional (nível sistema de saúde)
