# Prompt 7

🎯 PROMPT DE CORREÇÃO — LOGO NÃO APARECE NO LINK (FIGMA / FIGMAFAKE)
Corrigir o problema em que a logo do aplicativo não aparece ao compartilhar o link de visualização, garantindo que todos os elementos visuais sejam carregados corretamente para qualquer usuário.
🚨 1. PROBLEMA
Ao compartilhar o projeto:
A logo não aparece Pode estar quebrada ou invisível Outros usuários não conseguem visualizar 🔍 2. POSSÍVEIS CAUSAS (VERIFICAR E CORRIGIR) 🖼️ 2.1 IMAGEM NÃO INCORPORADA Problema:
A logo foi inserida como:
Link externo Ou imagem não embedada ✅ Solução: Reimportar a logo diretamente: 👉 Drag & drop no Figma 👉 Ou “Place Image” Garantir que: ✔ A imagem está dentro do arquivo ✔ Não depende de link externo 🔒 2.2 PERMISSÃO DE ACESSO Problema:
A imagem pode estar em:
Drive privado Conta restrita ✅ Solução: Usar imagem local (upload direto) Ou garantir: 👉 Permissão pública 🧱 2.3 COMPONENTE QUEBRADO Problema:
Logo está dentro de componente com erro
✅ Solução: Verificar instância Resetar componente (Reset Instance) Ou recriar a logo como elemento simples 🎭 2.4 OPACIDADE / VISIBILIDADE Problema:
Logo invisível por:
Opacity = 0% Cor igual ao fundo ✅ Solução: Opacity: 100% Ver contraste com fundo Ver se não está atrás de outro elemento 📦 2.5 FRAME / EXPORTAÇÃO Problema:
Logo fora da área visível
✅ Solução: Garantir que está dentro do Frame Não ultrapassa limites Não está em grupo oculto 🛠️ 3. PADRÃO CORRETO PARA LOGO
Aplicar:
Formato: PNG ou SVG Tamanho adequado Inserida diretamente no Figma Dentro do frame principal Sem dependência externa 🧪 4. TESTE FINAL (OBRIGATÓRIO)
Após corrigir:
Copiar link do projeto Abrir em: Aba anônima Outro navegador Outro dispositivo
✔ Verificar se a logo aparece corretamente
🎯 RESULTADO ESPERADO
Antes: ❌ Logo quebrada ou invisível
Depois: ✅ Logo visível para qualquer pessoa com o link ✅ Sem dependência externa ✅ Renderização correta
🔥 RESUMO
✔ Reimportar a logo (evitar link externo) ✔ Garantir permissões ✔ Verificar visibilidade ✔ Testar fora da conta
