# Evolução do Projeto — HelpHope

## Sobre esta Pasta

Esta pasta foi criada para documentar visualmente a evolução do projeto **HelpHope** ao longo do seu desenvolvimento.

As imagens presentes em cada versão representam momentos importantes da construção do protótipo, permitindo acompanhar as principais mudanças realizadas durante o projeto.

---

## Estrutura

```text
evolucao/
├── README.md
├── V1-Inicial/
├── V2-Intermediaria/
└── V3-Final/
```

---

## V1 — Inicial

A pasta **V1-Inicial** contém capturas de tela da primeira versão do projeto.

Nesta etapa foram desenvolvidas as primeiras ideias, layouts e funcionalidades iniciais que serviram como base para o restante do desenvolvimento.

---

## V2 — Intermediária

A pasta **V2-Intermediaria** contém capturas de tela da fase intermediária do projeto.

Nesta etapa foram realizadas melhorias de interface, organização das telas, ajustes de navegação e inclusão de novas funcionalidades.

---

## V3 — Final

A pasta **V3-Final** contém capturas de tela da versão final do projeto.

Esta etapa representa o resultado final do desenvolvimento, contendo as melhorias, correções e refinamentos realizados ao longo do projeto.

---

## Objetivo

O objetivo desta documentação é demonstrar de forma visual a evolução do HelpHope, permitindo acompanhar o progresso do projeto desde sua concepção inicial até a versão final apresentada.
